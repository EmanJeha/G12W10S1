Connection Games: setup guide

Grade 12 · Unit 4 · Week 10 · Session 1 · Complex Data Connections · Slides 1–39. Two live games and the Graph Lab: Line or Web? (warm-up) and Web Quest (wrap-up).

Firebase is already set up and config.js is already filled in. Just do step 1: create a new repository called G12W10S1 and upload these files. Scores for these games are kept separate from all your other games.

In these games
  • Mystery topic in the warm-up: every right answer flips three letters of COMPLEX DATA CONNECTIONS.
  • Sort-into-groups cards: line vs web, linear vs non-linear structures, problem vs fix.
  • Order the tiles (playlist, Matplotlib setup steps), tap the line of Python code that holds the links, spot the cycle danger.
  • 🔥 Streak bonus, 3-2-1-GO countdown, live moves feed, class accuracy and auto-results on your board.
  • Graph Lab (lab.html): students place and link cities, build a linear line then make it non-linear, traverse it, find a cycle and copy the matching Matplotlib code. Live missions, a progress bar, Show me demos and a certificate to screenshot when they reach 100%. Works on phones too.

1Put the games on GitHub Pages

  1. On github.com click New repository. Name it exactly G12W10S1, set it to Public, and create it.
  2. Click uploading an existing file. Drag in all the files from this folder (not the folder itself). Click Commit changes.
  3. Open Settings → Pages. Under Build and deployment choose Deploy from a branch, branch main, folder / (root), and click Save.
  4. Wait 1–2 minutes and refresh. The games are now at https://emanjeha.github.io/G12W10S1/
  5. If you use a different repository name, open config.js and change SITE_URL to match. (The lesson page also uses this address for its QR codes.)

2Suggested lesson flow

Step 1Warm-up game (Line or Web?). Open board.html?game=warmup, students scan and join, press Start.
Step 2Connection Web and Line or Web? warm-ups, journey and vocabulary (slides 2–6).
Step 3What is a data structure?, types, linear vs non-linear (slides 7–9).
Step 4Where non-linear shines and the challenges (slides 10–12).
Step 5Python + Matplotlib drawing, Sort It Out and Pitch It (slides 13–18). Try the city-graph code runner and the sort board.
Step 6Graph Lab. Show the QR code or paste https://emanjeha.github.io/G12W10S1/lab.html in the chat. Students work through the missions; Show me replays each one.
Step 7Wrap-up game (Web Quest), 3D recall video, recap and exit ticket (slides 19–39). Press Switch to Web Quest, Start, then Show answers.

3Run it in class

Shared screenOpen https://emanjeha.github.io/G12W10S1/board.html?game=warmup and press Full screen, then share that tab in your online meeting. The QR code and join link appear on the left.
StudentsOne device each (or one per breakout pair). They scan the QR code or open the link, type their name and press Join.
StartPress Start game. Everyone sees 3-2-1-GO, then the questions. The board re-ranks live and shows each move in the Live moves feed.
EndResults open by themselves when everyone finishes. Or press End game to stop and show the podium and the hardest questions.
Wrap-upPress Switch to Web Quest. After it ends, press Show answers to read every exit ticket.
Next classPress New round (click twice). This clears the board for a fresh group.

4Good to know

  • Practice mode: without internet access to Firebase, students can still play, but nothing appears on the board.
  • Refreshing is safe: if a page reloads, the student continues where they were .
  • Late players can join at any time while the game is live.
  • Scoring: 100 points per correct answer, up to 50 for speed, and a streak bonus (+20, +40, +60) from the 3rd right answer in a row. In the warm-up, cracking the mystery topic is worth +200.
  • Keyboard: on a laptop, students can answer multiple-choice with keys 1–4 or A–D and press Enter for the next question.
  • Changing questions: edit questions.js in GitHub (pencil icon) and commit. The top of that file explains each question type.
  • Who can control the board: anyone who opens board.html can press Start or End, so don't share that link with students.

5If you ever need a new Firebase

  1. Go to console.firebase.google.com, create a project, then Build → Realtime Database → Create Database (location europe-west1), test mode.
  2. In Rules, paste {"rules":{"sessions":{".read":true,".write":true}}} and click Publish.
  3. In Project settings → Your apps → </>, register a web app and copy the values into config.js.
